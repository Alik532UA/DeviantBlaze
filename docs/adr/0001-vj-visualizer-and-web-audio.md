# ADR 0001: Web Audio API, інтерактивний VJ-візуалізатор та векторна 3D-фізика логотипу

## Статус

Прийнято

## Контекст

Офіційний музично-візуальний портал рок-гурту Deviant Blaze вимагає виразного кіберпанк/готичного естетичного стилю, занурення слухача в атмосферу композицій та надання інтерактивного аудіо-візуального досвіду прямо у браузері без завантаження сторонніх важких бібліотек (Three.js/Babylon.js). Портал повинен працювати як при автономному прослуховуванні через мікрофон, так і з синтезатором фортепіано (Piano Modal).

## Рішення

1. **Реактивний Web Audio синтезатор та аналізатор:**
   - Використати `AudioContext`, `AnalyserNode` (FFT-аналіз частотних діапазонів бас/середина/верх) та синтезатор поліфонічних тонів на осциляторах (`OscillatorNode` + `GainNode` envelope ADSR).
   - Забезпечити підтримку альтернативних джерел аудіо (мікрофонний потік `navigator.mediaDevices.getUserMedia` з гнучкою чутливістю або прямий синтез).
2. **Апаратний VJ Canvas візуалізатор:**
   - Фоновий рендерер візуальних ефектів у реальному часі через `requestAnimationFrame` на `<canvas>`.
   - Режими візуалізації: спектральні смуги (`bars`), концентричні кола (`radial`), звукова хвиля (`wave`), частинки піску (`particles`).
   - Палітри кольорів: `blaze` (вогняно-бурштиновий), `neon` (кіберпанк ціан/маджента), `acid` (отруйно-зелений), `mono` (монохромний мінімалізм).
   - 5-секундний таймер неактивності для автоматичного занурення (VJ Dimming / Inactivity Mode) з плавним згасанням периферійних інтерфейсів.
3. **Векторна 3D-динаміка логотипу:**
   - 14 окремих інтерактивних гліфів та крил логотипу, згрупованих в SVG.
   - Фізика пружного відхилення (lerp physics) при наведенні курсору на десктопі та підтримка гіроскопа (`deviceorientation`) на мобільних пристроях.
   - Повний супровід доступності `prefers-reduced-motion` для користувачів із вестибулярними порушеннями.

## Наслідки

- Нульова залежність від зовнішніх 3D рушіїв; миттєвий перший рендер (FCP < 0.6s).
- Повний контроль над CSP: політика не вимагає `unsafe-eval` чи сторонніх скриптів для 3D графіки.
- Гнучке керування звуком та візуалом з можливістю підключення будь-яких пристроїв введення.
